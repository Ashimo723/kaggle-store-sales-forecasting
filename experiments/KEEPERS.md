## 固定している検証条件（変更したら全数値が比較不能になる）
- 指標: RMSLE（log1p 空間の RMSE）
- **主検証 = `src/cv3.py`（27 fold rolling origin）**: 2016-06-01 から16日ステップ、train = date < valid_start
  - **判定は必ず「同一 fold での対比較」**（差分 sd 0.0076-0.0128 → SE 0.0017）。平均の比較は fold 間 sd 0.0693 のため不可
  - **★★採否基準（2026-09-09 再改訂）= 次の3つを**すべて**満たすこと:
    1. 勝率 >= 85%
    2. 中央値 <= 平均差（利得が一様に分布、少数 fold が平均を作っていない）
    3. **最悪 fold の悪化 <= +0.002**（採用済み3施策はすべて +0.0010 以下、再帰予測は +0.0074 で LB 逆転）
  - 旧基準（2026-09-07）= 勝率 >= 85% かつ 中央値 <= 平均差、または |t| >= 3
    - |t|>=3 単独では外れ値に脆い。family blend は t=-1.32 だが勝率96%・中央値>平均で LB 転移率1.2、
      hl=365 は t=-1.76 だが中央値<平均（少数foldが利得を作る形）で LB +0.0225 の逆転だった
  - 勝率と中央値も併記する（少数の異常 fold が平均を作っていないかの確認。hl365 は 2016-12-26 単独で平均差の1/3を作っていた）
  - 既知の不具合: 2016-12-10 fold は 12/25 欠測日で NaN になる（要修正）
  - cv3 の 27fold 平均 0.4406 は実測 LB 0.42567 と近い（旧 cv2 の 0.3828 は楽観的すぎた）
- ~~旧 cv2（seasonal 2fold）~~ → 標準誤差が大きすぎ、hl=180 と hl=365 で2度誤判定したため主検証から降格
- **単体 seed 間の sd = 0.0011**（e16）。単一 seed での比較は 0.001 級の差を区別できない → 重要な判定は複数 seed 平均で行う
- 補助: 旧5fold（2017-05-28..08-15 のローリング）。速いので探索段階のスクリーニングに使う
- ホライズン16日を厳守（日付基準 lag>=16）
- 乱数シード: 未定（決定論的手法のみのため未使用）
